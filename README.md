# CodeAlpha Sales Prediction

## Project Overview

This project predicts product sales based on advertising expenditure using Python and Machine Learning.

The project analyzes the relationship between advertising channels such as TV, Radio, and Newspaper and their impact on Sales. A Linear Regression model is trained to predict sales based on these advertising investments.

## Objectives

- Analyze the advertising dataset.
- Clean and prepare the data.
- Study the relationship between advertising expenditure and sales.
- Train a Machine Learning model.
- Predict sales using advertising data.
- Evaluate the performance of the model.
- Visualize the results using graphs.

## Dataset

The project uses an advertising dataset containing **200 records**.

### Features

- **TV** – Advertising expenditure on TV
- **Radio** – Advertising expenditure on Radio
- **Newspaper** – Advertising expenditure on Newspaper

### Target Variable

- **Sales** – Sales generated from the advertising expenditure

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Machine Learning Model

The project uses **Linear Regression** to predict sales.

The dataset is divided into:

- **80% Training Data**
- **20% Testing Data**

The model uses TV, Radio, and Newspaper advertising expenditure as input features and Sales as the target variable.

## Model Evaluation

The model is evaluated using:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

The actual performance values are generated by the Python program and saved in the project report.

## Visualizations

The project generates the following visualizations:

1. Sales Distribution
2. TV Advertising vs Sales
3. Radio Advertising vs Sales
4. Newspaper Advertising vs Sales
5. Actual Sales vs Predicted Sales
6. Impact of Advertising Channels on Sales

The Sales Prediction project demonstrates how Machine Learning can be used to predict sales based on advertising expenditure.

Linear Regression is used to understand the relationship between advertising channels and sales and to generate sales predictions.
